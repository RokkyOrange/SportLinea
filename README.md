# БК «СпортЛиния» — Информационная система букмекерской конторы

Курсовой проект по МДК 01.01 «Разработка программных модулей».

## Технологический стек

- **Сервер:** ASP.NET Core 9.0 (C#), MVC
- **БД:** Microsoft SQL Server (LocalDB)
- **Клиент:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Аутентификация:** ASP.NET Core Identity

## Запуск

### Требования

- .NET SDK 9.0+
- SQL Server LocalDB (устанавливается с Visual Studio)

### Команды

```bash
cd SportLinea
dotnet run
```

Сайт откроется по адресу: https://localhost:5001 или http://localhost:5000

При первом запуске автоматически создаётся база данных и тестовые данные.

## Функциональность по ролям

### Гость
- Просмотр линии событий
- Просмотр итогов матчей
- Общий рейтинг игроков
- Регистрация

### Игрок
- Авторизация, личный кабинет
- Пополнение счёта, совершение ставок
- История ставок с фильтрацией
- Личная статистика, бонусы, уведомления
- Редактирование профиля

### Букмекер
- Создание и редактирование событий
- Управление коэффициентами
- Ввод результатов и автоматический расчёт ставок
- Реестр всех ставок, управление игроками
- Назначение бонусов, отчёты, экспорт в Excel

### Суперпользователь
- Создание учётных записей букмекеров
- Журнал действий
- Резервное копирование данных

## Строка подключения

По умолчанию в `appsettings.json`:

```
Server=(localdb)\mssqllocaldb;Database=SportLineaDb;Trusted_Connection=True;...
```
